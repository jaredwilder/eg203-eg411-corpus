# Patch - Tate-Module Finite-Linear Port

For any finite-dimensional \(\mathbb F_\ell\)-space \(V\), operators \(T_q\), and vectors \(v_1,\ldots,v_r\), define
\[
\Psi_S:\mathbb F_\ell^r\to V^S,
\qquad
c\mapsto\left((T_q-I)\sum_j c_jv_j\right)_{q\in S}.
\]
Then
\[
\dim\operatorname{coker}\Psi_S=|S|\dim V-\rank\Psi_S.
\]

For an elliptic curve \(E/\mathbb Q\), taking \(V=E[\ell]\) and \(T_q=\rho_{E,\ell}(\operatorname{Frob}_q)\) gives
\[
\dim D_{\ell,E}(S)=2|S|-\rank\Psi_S.
\]
