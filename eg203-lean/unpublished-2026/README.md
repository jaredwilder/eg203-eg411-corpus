# EG203 Lean files not previously published

These are every EG203 Lean file from the working tree that wasn't already in this repo, published as they are.

Many of them are close attempts that depend on project-specific axioms, from the line of work withdrawn in June 2026 (`AxiomatizedClose`, `EG203NamedAxiomClose`, `EG203UnconditionalClosure`, `EG203FromTightenedAxioms` and similar). **None of them proves Erdős–Graham #203**, which is still open. Check `#print axioms` before relying on any file here. The others are sieve, Mertens and prime-gap support files, witness certificates, and versions of files that also appear elsewhere in the repo.
